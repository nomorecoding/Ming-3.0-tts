01Abilities

One framework. One task per call.

Getting a line of speech right is rarely just a matter of reading the words. Which voice is this character? How should the line land? Where does it pause, laugh or sigh? Which language is it, or which dialect? Ming-3.0-tts brings voice, delivery, non-verbal sounds, language, dialect and attribute controls into one speech-generation framework. Each generation is one task; the controls below are not combined in a single call.

01

Start from the character, not from a clip

No reference recording that sounds right? Describe the voice by age, texture, temperament and role, and Voice Design renders it with no audio at all. Or pick one of 479 built-in Chinese voices and five English ones, or clone from a short reference.

A description, a built-in name and a reference clip are three separate calls; none of them also takes emotion, dialect, speed or a freeform instruction.

InstructTTSEval-ZH
tiny ranks 2nd among the compared models on average ACC (75.37%), APS (85.10%) and DSD (79.90%).

02

Direct the line in plain words

Freeform is its own task: one instruction, not a voice-design description and not a built-in voice. On 0.5b the instruction can follow a reference clip or, with no reference, choose the voice; tiny always needs the reference clip.

Does not take emotion, dialect, speed, pitch, volume or inline tags.

“Like telling an old friend about the past: warm, close, a little nostalgic.”
Listen
03

Laughs and sighs belong in the script

Fourteen inline tags cover breath, cough, sigh, laughter, hesitation, surprise, and question and confirmation particles. Written where they happen, they are performed in the reference speaker's voice, in Chinese or English cloning.

Not accepted on voice design, built-in voices, dialect, emotion, attribute control or the five new languages.

NVBench
Together the two variants are SOTA on all six single-tag metrics; tiny is SOTA on all three English multi-tag metrics.
Listen
04

Seven languages on a cloned voice, dialects on their own call

Chinese and English use the cloning task; German, Spanish, French, Korean and Japanese use the multilingual task, one language per call from a reference clip. Sichuanese and Cantonese are a separate dialect task on a reference voice.

The dialect task has no target-language setting and does not take emotion, speed or tags.

Multilingual and dialect
tiny is SOTA on German (0.325%) and Spanish (0.971%) WER, Sichuanese Hard CER (3.11%) and Easy accuracy (86.09%); 0.5b is SOTA on Cantonese Base CER (6.15%) and dialect accuracy (98.00%).
Listen
05

Control when it matters

Emotion is one task (高兴, 悲伤, 愤怒, 恐惧, 厌恶, 惊讶, 中性). Speed, pitch and volume are a different task and are set together (慢速 / 中速 / 快速; pitch and volume 低 / 中 / 高).

Neither task takes a target language, a dialect, tags, or a designed or built-in voice.

Attribute control
0.5b leads the compared models on average accuracy (93.30%) and pitch (86.00%); tiny leads on WER (0.274%) and SIM (0.742).
CV3 and CV3N emotion
tiny ties for SOTA on text-related Happy (98%) and 0.5b is SOTA on text-related Angry (94%); on CV3N, tiny is SOTA on both Sad subsets.
Listen
06

A whole conversation, not stitched lines

Give tiny one short reference per speaker and a speaker_1: / speaker_2: script, and it performs the dialogue in one pass, turn-taking included.

Podcast is tiny only and does not take a target language, emotion, dialect or tags.

CER 2.03% ranks 1st and cpSIM 0.561 ranks 2nd among the compared podcast systems.

02Architecture

One sequence, many controls.

Text and task-specific control tokens condition a language model with a DiT patch head and an audio tokenizer. Both models share this generation framework.

Target language, a freeform instruction, paralinguistic tags and structured controls share one prompt format: they are ordinary tokens next to the text. A single request fills the slots for one task. Voice design, a built-in voice, cloning, freeform, emotion, speed/pitch/volume, dialect, paralinguistic tags and podcast are not combined. The public APIs expose that split, shown in the Cookbook.

05Get started

Run it yourself.

Weights for both variants are on Hugging Face and ModelScope. Installation, inference examples and the task cookbook are in the repository.

GitHub Quick Start Cookbook 
pip install "huggingface_hub[cli]"
hf download inclusionAI/Ming-3.0-tts-0.5b \
  --local-dir Ming-3.0-tts-0.5b

# In mainland China, ModelScope is usually faster
pip install modelscope
modelscope download --model inclusionAI/Ming-3.0-tts-0.5b \
  --local_dir Ming-3.0-tts-0.5b
