# Ming-3.0-tts demo page

Source of the project page for [Ming-3.0-tts](https://github.com/inclusionAI/Ming-3.0-tts), served by GitHub Pages from `main`.

The demo tables are data, not HTML: edit `static/js/examples.js`. To publish a sample, put the audio (mp3 keeps the page light) under `static/audio/<section id>/` and set the row's `audio` field to its path. Rows without audio render with an empty Result cell.

Preview locally by opening `index.html` in a browser.
